# Hotel-Room-Reservation-Tracker
Hotel Room Reservation Tracker


The Hotel Room Reservation Tracker is a Java desktop application designed to manage hotel room reservations. It allows users to add rooms, display room information, search for rooms, assign rooms to guests, and vacate rooms.


Features

- Add Room
- Display Rooms
- Search Room by Room Number
- Assign Room to Guest
- Vacate Room
- Room Availability Tracking
- Object-Oriented Programming
- Java Swing GUI

## Data Structure and OOP Implementation

The system uses a manually implemented array to store room objects. The `RoomManager` class handles room management operations, including adding, displaying, and searching for rooms.

The project also demonstrates the following OOP concepts:

- Encapsulation
- Inheritance
- Classes and Objects
- Constructors
